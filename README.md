# Codigo-Orientado-a-Objeto
Um código simples orientado a objeto, onde trabalha com hierarquia de classe.

---
Um código em Java, onde irá trabalhar com hierarquia de classes, famosa pela Herança de Programa Orientada a Objeto.

A sua base é definida dessa forma:
Classe base carro
Classe subclasse esportivo 

A classe carro vai herdar tudo que tem, mas adiciona ou modifica comportamentos específicos da classe carro esportivo e o seu motor mais potente. 

Segue abaixo a informação que se tira do código ao debuggar:
