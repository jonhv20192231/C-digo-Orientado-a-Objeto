🚗 Projeto: Orientação a Objetos em Java
Uma demonstração prática e estruturada dos pilares da Programação Orientada a Objetos (POO) em Java, focando principalmente no uso de Herança, Composição e Encapsulamento.

📌 Sobre o Projeto
O sistema simula a estrutura e o comportamento de veículos através de uma hierarquia de classes:

Classe Base (Carro): Define a estrutura genérica de um veículo (Marca, Modelo, Ano, Quilometragem).

Subclasse (CarroEsportivo): Herda as características da classe Carro, mas estende suas funcionalidades adicionando parâmetros de alta performance, como Velocidade Máxima e comportamentos de aceleração customizados.

Composição (Motor): Demonstra a relação onde um veículo possui um motor, permitindo gerenciar o tipo de combustível, potência e estado (ligado/desligado).
